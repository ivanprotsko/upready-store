# Image generation — what goes into pixels vs what goes into CSS (2026-09-08)

Иван поймал глазами (2026-09-08): hero-фон во всех пяти живых темах несёт впечённый слева
градиент-затемнение. Пример — electronics, Defect 3 в `artifacts/docs/2026-09-08-wave-electronics.md`:
«900px товар на канвасе 1920×900, ramp в `#0d1013` до 62% ширины» сделан НАМЕРЕННО, по style board §6
(«backdrop darkening leftwards into --background... in the photograph rather than as a scrim»).
Итог: изображение годится ровно под один кроп, одну позицию текста, одну тему — переиспользовать в
другом контексте нельзя. Журнал: `aie-20260908-211150-02e2`.

## Правило

Генерируемое/композитное изображение несёт только то, что **нельзя** сделать вёрсткой поверх чистого
кадра: сам предмет, его свет, фактуру, композицию съёмки.

Всё, что воспроизводимо CSS (`linear-gradient`/`radial-gradient` поверх `<img>`, `mix-blend-mode`,
цветной оверлей) — **не запекается в файл**: затемняющий ramp, виньетка, цветная подложка под текст,
леттербоксинг. Запечёшь — картинка живёт ровно там, где её впекли; оставишь CSS — тот же кадр идёт
и в hero, и в плитку категории, и под другую пропорцию, и под другую тему без пересъёмки.

## Где применяется

- **Style board, раздел «фотонаправление»/концепт hero** (стадия S2, роль «креативный директор») —
  бриф формулирует кадр БЕЗ эффекта, эффект — отдельная строка «CSS: линейный градиент слева, X% →
  `--background`» для инженера профиля витрины.
- **Любой пост-процессинг генерации** (canvas/sharp композиция перед сохранением в манифест) —
  затемнение принадлежит компоненту hero в коде, не пиксельному проходу.
- Негативные промпты продуктовых кадров (`apps/backend/scripts/store-media/prompts.mjs`) уже
  исключают «gradient background, coloured background» — hero/lifestyle-брифы такой защиты не имеют,
  потому что пишутся creative-director-агентом вручную под каждую тему; этот файл — их защита.

## Не применяется к

Эффектам, которые правда часть отснятой сцены (собственная тень предмета, блеск материала,
студийный свет в кадре) — это свойство кадра, не оверлей поверх него.

## Ретрофит — вне области этого правила

Правило смотрит только вперёд (директива Ивана, 2026-09-08). Пять уже отгруженных hero-изображений
остаются с впечённым градиентом до отдельного заказа на пересъёмку/перекомпоновку.
