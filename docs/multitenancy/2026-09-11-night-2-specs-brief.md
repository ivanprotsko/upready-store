## 1. Принцип: схема = зеркало кода, с датой и коммитом

- Каждый документ и каждая схема несёт frontmatter: `id`, `kind` (er | sequence | flowchart | state | c4-context | c4-container | gantt | route-map | glossary), `status` (`as-is` — отражает код на коммите; `to-be` — целевое, со ссылкой на задачу `t-…`), `created`, `updated` (ISO, WITA), `verified_against` (sha коммита, по которому сверено), `verified_at`, `generator` (`script:<имя>` | `hand`), `sources` (файлы кода, которые схема отражает).
- Реестр — **JSON**, не markdown (18b): `docs/specs/registry.json` — те же поля на каждую схему; markdown-файлы схем ссылаются на id. Правило доверия пишется в `docs/specs/README.md` одной фразой: «если `verified_against` — не предок HEAD или `sources` менялись после него — схеме не верить, идти в код».
- **Генерируется из кода всё, что можно:** ER (из `model.define` в `apps/backend/src/modules/**/models/*.ts` + `defineLink` в `src/links/*.ts`), карта маршрутов (из `apps/backend/src/api/**/route.ts` — экспортированные методы, actor type по каталогу `admin|store|tenants|auth`), шаги workflow (из `src/workflows/**` — `createStep`/`runAsStep`), gantt (из `HANDOFF.json`: created/approved/updated/done задач `t-…-mt-…`). Скрипт `specs-generate.mjs` пишет их в `docs/specs/generated/*.md` со штампом коммита.
- **Рукописные схемы** (sequence, flowchart, c4, state): рисуются по коду, `sources` перечисляют файлы; `specs-verify.mjs` для каждой считает `git diff --name-only <verified_against>..HEAD -- <sources>` — если непусто, схема помечается STALE в отчёте; для generated — регенерирует и сравнивает с закоммиченным, дрейф = FAIL. Выход ≠0 при дрейфе. Отчёт `docs/specs/verify-report.md`; `registry.json` обновляется (`verified_at`/`verified_against`) только при зелёном прогоне. Скрипт прогнать самому (19c), команду записать в README и в `AGENTS.md` (раздел проверок); подключение к хуку/CI — вопрос Ивану (`question add`), не самовольно.
- Формат схем — mermaid внутри markdown (рендерится в артефактах и на GitHub). BPMN — только через генерацию из IR (29a); руками не рисовать.
