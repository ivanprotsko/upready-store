# Customer account pages (D3) — ASCII mock-up of every state

Design stage for Ivan's task 3 (`t-2026-09-09-02`, every account mockup seen, every interaction walked through), written before code (rule 27d). Scope: login, register, overview, orders list, order details, addresses, profile, nav. Checkout/payment/pickup-point *selection* are D1/D2's scope (`artifacts/docs/2026-09-09-checkout-account-map.md`); this document draws pickup-point *display* on an already-placed order only. **Budget note**: to fit the 400-line cap, once a reflow pattern is shown in full, a later screen's mobile frame is drawn compact (content only, chrome by reference).

Canon: the storefront's preset theme system (`src/styles/themes.css`, generated by `scripts/build-themes.mjs`, bridged into `@medusajs/ui` classes) — every frame renders under all seven presets/both modes via `text-ui-fg-*` classes, never raw color. The workspace typography discipline (`~/upready/packages/geist-kit/AGENTS.md`) still applies: sentence case, weight ≤ 600, one accent, tabular-nums, hairline borders, status = 8 px dot + text — the last of which the shop code does not follow today (facts table). Store = `Kerbstone` (sneakers, `localhost:8028`). Sample order content is real seed data (product/prices and pickup address, cited in the facts table).

## Acceptance by eye (rule 27d)

1. No identifier reaches the screen without its label — status always renders through
   `fulfillmentStatuses`/`paymentStatuses`, never a raw `fulfilled`/`not_paid` string.
2. No title/address/product name is truncated at 390 px — checked against the longest real strings
   used: "At the pickup point" (§4b), "Pennsylvania Avenue NW 1600" (§5a), real catalog titles.
3. No list runs longer than one screen without a search — orders/addresses per demo customer stay
   well under a screen's worth; flag again if seed data grows past it.
4. Status = 8 px dot + text, never a raw enum or bare pill (§2a, §3a, §4a).
5. Section/row/meta read apart visually — profile's label/value/edit triad (§6a), nav's accent bar
   (§7a), order card's heading/meta/thumbnail rows (§3a).
6. Every frame above is drawn, not described in prose.
7. **Own** — the timeline's current step is never ambiguous: one half-filled connector, everything
   before it fully filled; two steps can never both look "current."
8. **Own** — every visitor action leaves a visible trace: an address save closes into an updated
   tile (§5a), a profile save into an updated value row (§6a), never back to an unchanged screen.
