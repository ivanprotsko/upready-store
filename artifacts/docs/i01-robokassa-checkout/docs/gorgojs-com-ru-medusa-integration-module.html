Модуль интеграций для Medusa

Модуль интеграций

No-code UI для настроек плагинов Medusa

Плагин описывает свои параметры в виде схемы, а администратор управляет ими в Medusa Admin, без правок medusa-config и без повторного развёртывания. UI, хранение, шифрование и валидацию берёт на себя модуль.

Обзор

Сделано для тех, кто управляет магазином

Модуль генерирует полноценный UI настроек для каждого плагина по его декларативному описанию. Страницы в Admin писать не нужно, разворачивать проект заново тоже.

UI настроек без кода

Учётные данные, режимы и вебхуки собраны в разделе Настройки → Интеграции. Измените значение, и оно вступит в силу сразу.

Шифрование по умолчанию

Параметры с пометкой secret модуль шифрует при хранении алгоритмом AES-256-GCM, и они никогда не уходят в браузер.

Проверка соединения

Проверьте подключение к внешнему сервису прямо из Admin, дальше модуль делает это сам каждый день. Нерабочий ключ вы увидите в настройках, а не при оформлении заказа.

Любой плагин, провайдер или модуль

Платежи, доставка, уведомления, ERP, контент или ваш собственный модуль. Если настройкой должен управлять администратор магазина, это можно сделать через Модуль интеграций.

Несколько инстансов

Подключите один и тот же провайдер несколько раз, например, основной и резервный шлюз или отдельный аккаунт на регион. У каждого инстанса свои настройки.

Возможности

Первоклассный UI настроек для любого плагина, без кода

Легко разработчикам интеграций, удобно администраторам магазинов.

Разработчикам

  • Один декларативный дескриптор для всех настроек плагина

  • Параметры, секции, валидация и проверка соединения в одном файле

  • Модуль генерирует UI и API, вам не нужно ничего писать самостоятельно

  • Типизированные параметры: string, url, email, uuid, number, boolean, enum, json

  • Правила валидации на уровне параметра и между секциями

  • Условная видимость и поля read-only

  • Читайте типизированные расшифрованные значения параметров где угодно

  • Подключите собственный виджет, если готовых секций не хватает

  • Локализуйте свои настройки с помощью штатного i18n

Администраторам магазина

  • Все настройки плагинов и провайдеров в одном месте

  • Смена значений не требует правок medusa-config и повторного развёртывания

  • Понятный статус: не настроено, не завершено, включено, выключено

  • Несколько инстансов одного провайдера для разных аккаунтов, регионов или целей

  • Шифрование секретов при хранении алгоритмом AES-256-GCM

  • Проверка соединения по кнопке и ежедневная автоматическая перепроверка

  • Выключайте интеграцию, не теряя введённых значений

  • Ищите готовые интеграции в каталоге прямо в Admin
