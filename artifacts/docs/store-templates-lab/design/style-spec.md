# Спецификация стиля — один язык для всех шаблонов

Один дизайн-язык, видимый на каждой странице каждого шаблона. Документ отвечает на два вопроса:
**что у всех шаблонов общее** (и потому машинно проверяется) и **чем шаблону можно отличаться**
(и потому объявляется токеном). Всё, что здесь названо, реализовано в `src/tokens/base.css`;
то, чем шаблон отличается, — в `src/tokens/<шаблон>.css`.

Основания: канон Geist (`~/upready/packages/geist-kit/AGENTS.md`, правило 27), словарь токенов
витрины (`specs/design-system/themes/*.theme.json`, 31 токен), десять правил композиции
(`~/upready/memory/page-composition-rules-storefront-2026-09-09.md`), диагноз живого магазина
(`design/diagnosis.md`) и правила проверки (`design/quality-rules.md`).

**Совместимость с витриной.** Имена цветовых ролей взяты из витринного словаря один в один
(`--background`, `--foreground`, `--card`, `--border`, `--muted-foreground`, `--primary`, `--link`, …),
поэтому перенос шаблона на storefront — это подстановка значений в уже существующий контракт,
а не новая система. Лаборатория добавляет к словарю семь имён, которых витрине не хватает
(раздел «Добавления к словарю витрины»).

## 1. Типографическая шкала

Модульная шкала с отношением **1.25** (большая терция) от базы 16 px. Семь ступеней — ровно столько,
сколько допускает `QR-TYPE-SCALE` (≤ 8), и ни одной пары ближе 1.15.

| Токен | Десктоп | Мобиль (<640px) | Интерлиньяж | Трекинг | Роль |
|---|---|---|---|---|---|
| `--text-display` | 49px | 39px | 1.05 | −0.04em | заголовок hero |
| `--text-h1` | 39px | 31px | 1.15 | −0.03em | заголовок страницы |
| `--text-h2` | 31px | 25px | 1.25 | −0.02em | заголовок раздела |
| `--text-title` | 25px | 20px | 1.30 | −0.01em | подраздел, цена на товаре |
| `--text-lead` | 20px | 20px | 1.50 | 0 | лид, крупная подпись |
| `--text-body` | 16px | 16px | 1.60 | 0 | тело, название карточки |
| `--text-meta` | 12px | 12px | 1.45 | 0 | мета, надглавие |

Отношения соседей: 1.33 · 1.25 · 1.25 · 1.24 · 1.26 · 1.26 — каждая ступень различима.
На мобиле верхние три ступени опускаются на рунг вниз; нижние четыре не меняются, поэтому
тело текста читается одинаково на обоих вьюпортах.

**Голос даёт трекинг, а не жир.** Максимальный вес — **600** (канон Geist). Веса ровно три:
400 (тело), 500 (подписи, кнопки, мета-акцент), 600 (заголовки, цена).

**Прописные — только надглавие:** `--text-meta` (12 px), моноширинный, `letter-spacing: .08em`.
Больше нигде, словесный знак включительно (`QR-CASE`).

**Длина строки.** Проза набирается в колонке, дающей **60–75 знаков** (`--measure: 68ch` как
максимальная ширина текстового блока). Предел проверки — 45…90 (`QR-MEASURE`).

## 2. Шкала отступов

Ровно десять ступеней, все кратны 4, ни одного значения вне шкалы (`QR-SPACE-SCALE`):

```
--space-1: 4px    --space-6:  24px   --space-24:  96px
--space-2: 8px    --space-8:  32px   --space-32: 128px
--space-3: 12px   --space-12: 48px
--space-4: 16px   --space-16: 64px
```

1 px существует только как толщина границы, не как отступ. Значений 2, 6, 10, 28 px в системе нет.

**Ритм полос.** Вертикальный зазор между блоками верхнего уровня — **одно** значение на страницу,
`--band-y` (задаётся плотностью). Смежные родственные блоки (заголовок раздела и его сетка)
используют `--band-y-tight` = половина. Больше двух значений на странице — отказ
(`QR-SECTION-RHYTHM`).

## 3. Контейнер и сетка

```
--container: 1200px     ширина содержимого
--gutter:    24px       поля (16px на мобиле)
--grid:      12         колонок
--grid-gap:  var(--card-gap)
--measure:   68ch       максимум для прозы
```

**Одна вертикаль на весь сайт.** Каждый блок кладёт содержимое в `.container` — левый край один и тот
же на всех страницах шаблона (`QR-GRID-AXES`). Блок во всю ширину объявляет это атрибутом
`data-bleed`, и только он имеет право выходить за контейнер.

**Сетка выкладки** (число колонок — выбор шаблона, композиция):
десктоп 3 или 4, планшет 3, мобиль 2. Смена числа колонок допустима между БРЕЙКПОЙНТАМИ,
но не между страницами одного шаблона.

## 4. Цветовые роли

Словарь витрины, один в один. Шаблон переопределяет **значения**, никогда имена.

| Токен | Что это | Правило |
|---|---|---|
| `--background` / `--foreground` | полотно / основной текст | контраст ≥ 4.5:1 |
| `--card` / `--card-foreground` | поверхность карточки и её текст | карточка обязана иметь поверхность (`QR-CARD-SURFACE`) |
| `--secondary` / `--secondary-foreground` | мягкая заливка: полосы, активные строки | |
| `--muted` / `--muted-foreground` | приглушённая заливка / второстепенный текст | контраст ≥ 4.5:1 |
| `--primary` / `--primary-foreground` | главное действие (в корзину, оформить) | ровно одно главное действие в блоке |
| `--accent` / `--accent-foreground` | акцентная плашка: скидка, метка | |
| `--border` | волосяная граница 1px, всё разделение | одна толщина, один цвет |
| `--input` / `--ring` | поле ввода / кольцо фокуса | кольцо видимо всегда (`QR-FOCUS`) |
| `--link` | **единственный** акцент ссылок | не смешивается с `--primary` |
| `--destructive` | распродажа, ошибка, удаление | статус, не украшение |
| `--success` / `--warning` | в наличии / мало осталось | статус, не украшение |
| `--popover` / `--popover-foreground` | всплывающие поверхности | |

**Один акцент.** У шаблона ровно один цветной акцент (`--primary`), плюс `--link` для ссылок и
три статусных цвета. Второй декоративный цвет — нарушение канона Geist.

### Добавления к словарю витрины (чего витрине не хватает)

| Токен | Зачем | Диагноз |
|---|---|---|
| `--surface-media` | **одна** подложка под все товарные изображения | C3: белый, чёрный, красный, горный фон в одной сетке |
| `--aspect-card` / `--aspect-tile` / `--aspect-hero` / `--aspect-gallery` / `--aspect-thumb` | жёсткая коробка соотношения для каждой роли изображения | C1, C2, C6 |
| `--media-fit` | `contain` (паккшот) или `cover` (лайфстайл) — решение шаблона, а не блока | C4 |

Перенос на витрину: `--r-md` ≡ витринный `--radius`; остальные шесть имён добавляются в
`*.theme.json` как новые токены, значения по умолчанию — из `base.css`.

## 5. Радиусы, границы, подъём

```
--r-sm:   6px     контролы: кнопка, поле, чип
--r-md:   8px     карточки, изображения, панели
--r-lg:  12px     меню, модальные окна, ящик корзины
--r-pill: 9999px  только метка-пилюля и круглая иконка-кнопка
```

Радиусы **общие для всех шаблонов** — это одна из четырёх вещей, по которым стиль опознаётся.
Одна роль компонента — один радиус на всех страницах (`QR-RADIUS`).

**Границы.** Волосяная линия 1 px `--border` — единственный инструмент разделения.
Двухпиксельных рамок и цветных разделителей нет.

**Подъём.** Одна рецептура на шаблон, `--shadow-card`: набор мягких слоёв плюс волосяное кольцо
(светлая тема), в тёмной теме подъём даёт **граница**, а не тень (канон Geist).
Тяжёлой одиночной тени не существует (`QR-ELEVATION`).

## 6. Изображения

Самый дорогой раздел: именно изображения дали «кашу» в живом магазине.

1. **Жёсткая коробка всегда.** Каждое контентное изображение лежит в коробке с объявленным
   `aspect-ratio`. Скачка вёрстки и рендеринга 0×0 не существует (`QR-IMG-ASPECT`).
2. **Одна роль — одно соотношение.** Внутри шаблона роль `card` имеет одно соотношение на всех
   страницах. Между шаблонами соотношение может отличаться — но только из закрытого набора
   **1:1 · 4:5 · 3:4 · 3:2 · 16:9**.
3. **Миниатюра равна кадру.** `--aspect-thumb` = `--aspect-gallery`: миниатюра показывает ровно тот
   кроп, который откроется (`QR-GALLERY`).
4. **Одна подложка.** Все изображения ролей `card` и `tile` лежат на `--surface-media`. Разнородный
   фон чужих картинок гасится общей подложкой и общим внутренним полем.
5. **Вписывание — решение шаблона.** `--media-fit: contain` для паккшотов (товар в упаковке, чужая
   инфографика: ничего не режем) и `cover` для лайфстайла (кадр — аргумент). Смешивать внутри
   шаблона нельзя.
6. **Пустое состояние спроектировано.** Товар без фотографии рендерит заглушку **в той же коробке**:
   подложка `--secondary`, инициал названия в `--text-h2` цветом `--muted-foreground`, под ним
   название категории в `--text-meta`. Серого прямоугольника со значком не существует (`QR-EMPTY`).
7. **Альтернативный текст — на языке магазина**, непустой, описывает товар. `alt=""` — только у
   изображения с атрибутом `data-decorative` (`QR-ALT`).

## 7. Движение

```
--dur-fast: 120ms   наведение, фокус
--dur:      180ms   раскрытие, смена кадра
--ease:     cubic-bezier(.2, 0, 0, 1)
```

Ничего длиннее **240 ms**. Движение только у того, что реагирует на действие; появление контента
при прокрутке не анимируется. Блок `@media (prefers-reduced-motion: reduce)` обнуляет все
длительности и отключает `transform`-переходы (`QR-MOTION`).

## 8. Грамматика компонентов

Одна вещь — одна реализация. Ниже DOM-подпись (последовательность `data-role`), по которой
`check.mjs` сравнивает компонент между страницами (`QR-CARD-GRAMMAR`).

**Кнопка.** Три размера: `sm` 36px, `md` 44px, `lg` 52px — ни одна интерактивная цель не опускается
ниже 44 × 44 на мобиле (`QR-HIT`), поэтому на мобиле `sm` не используется. Радиус `--r-sm`,
вес 500, sentence case. Главная — заливка `--primary`; вторичная — волосяная граница на прозрачном;
третичная — только текст. В блоке одно главное действие.

**Ссылка.** Цвет `--link`, подчёркивание на наведении, не в покое; инлайновая ссылка внутри абзаца
не обязана держать 44 px (исключение WCAG 2.5.8).

**Карточка товара** — единственный компонент, который встречается на всех трёх страницах, и потому
главный носитель узнаваемости:
```
article[data-block=product-card]
  └ a[data-role=card-media]      → div[data-img-role=card] (коробка --aspect-card) → img | заглушка
  └ div[data-role=card-body]
      ├ span[data-role=card-badge]?    метка SALE/NEW/ХИТ — пилюля, --accent
      ├ h3 [data-role=card-title]      --text-body / 400, максимум 2 строки, многоточие
      ├ div[data-role=card-price]      --text-body / 600, tabular-nums
      │   └ s[data-role=card-price-old]?  --muted-foreground
      └ div[data-role=card-meta]?      фасовка, наличие — --text-meta
```
Название всегда занимает **две строки** (`min-height` = 2 × интерлиньяж), поэтому цены всего ряда
стоят на одной базовой линии независимо от длины названий.

**Цена.** `tabular-nums`, неразрывный пробел перед `₽`, копейки печатаются только когда они не нули.
Старая цена — зачёркнутая, `--muted-foreground`, всегда после новой (`QR-PRICE`).

**Метка.** Пилюля `--r-pill`, `--text-meta`, вес 500, sentence case (кроме моношириного надглавия).
Заливка `--accent` для NEW/ХИТ, `--destructive` для скидки. Не больше одной метки на карточке.

**Рейтинг.** Пять контуров, заполнение `--foreground` (не жёлтый — второй акцент запрещён),
рядом число в `tabular-nums` и количество отзывов ссылкой.

**Поле ввода.** Высота 44px, фон `--background`, граница `--border`, радиус `--r-sm`,
плейсхолдер `--muted-foreground`; фокус — смена цвета границы на `--ring`, без свечения.

**Вкладки.** Строка кнопок с нижней волосяной линией; активная несёт линию `--foreground` 2px.
На мобиле вкладки превращаются в аккордеон — та же разметка, другое поведение.

**Аккордеон.** Заголовок — кнопка на всю ширину (высота ≥ 44px), шеврон поворачивается на 90°
за `--dur-fast`; открыта одна секция.

**Шапка.** Иконок без подписи подряд — **не больше четырёх** (`QR-CONTROL-DENSITY`).
Язык, валюта и тема живут в одном меню, а не семью кнопками в ряд.

**Футер.** Полоса с поверхностью, отличной от полотна (`--secondary` или инверсия): низ тяжелее
верха (`QR-TECTONICS`, правило композиции 3).

## 9. Что шаблону можно менять, а что — нельзя

| | Общее для всех (стиль прослеживается) | Выбор шаблона |
|---|---|---|
| Типографика | шкала, отношение 1.25, интерлиньяжи, трекинги, потолок веса 600, роли | **пара шрифтов** (display + body) |
| Цвет | имена ролей, «один акцент», контраст AA | **значения палитры** |
| Отступы | шкала 4…128, одно значение ритма полос | **плотность** (compact / comfortable / spacious) |
| Сетка | контейнер 1200, один левый край, 12 колонок | **число колонок выкладки** (3 или 4) |
| Радиусы | 6 / 8 / 12 / pill | — |
| Границы, подъём | волосяная 1px, одна рецептура тени | — |
| Изображения | жёсткая коробка, одна роль — одно соотношение, одна подложка, спроектированная заглушка | **соотношение из закрытого набора**, `contain` или `cover` |
| Движение | длительности и кривая, `prefers-reduced-motion` | — |
| Грамматика компонентов | DOM-подписи, поведение, зоны нажатия | **композиция страницы** (какие блоки и в каком порядке) |

Машинное доказательство — таблица `QR-TOKEN-COVERAGE` в отчёте `check.mjs`: она печатает, какие
токены переопределяет каждый шаблон. Если в колонке переопределений появился `--text-*`,
`--space-*` или `--r-*`, стиль перестал быть общим, и проверка отказывает.

## 10. Composition — как собирается страница

Десять правил композиции применяются к каждому шаблону; здесь — те, что решают за генератор:

1. **Одна доминанта** на первом экране: либо hero-кадр, либо крупная типографика, не оба.
2. **Контраст масштабов:** соседние блоки отличаются модулем вдвое и больше.
3. **Тектоника:** низ тяжелее верха — инверсный или заливной футер.
4. **Кольцо:** словесный знак шапки рифмуется с крупным знаком в футере.
5. **Продолжение осей:** число плиток над сеткой делит число колонок сетки (4 над 4, 3 над 3).
6. **Ранг изображения:** крупный модуль — только если кадр различает товары.
7. **Запрет повтора фактуры:** два соседних блока не несут одинаковую фотофактуру.
8. **Неизбыточность:** маршрутизация происходит один раз — плитки категорий ИЛИ полоса категорий в шапке.
9. **Симметрия как язык:** осевая = институция, асимметричная = утилитарный магазин; внутри шаблона не меняется.
10. **Свиток, а не кадр:** доминанта и первый товар — до сгиба.

## §Checklist — то, что проверяют глаза

Приёмщик открывает `gallery/index.html` и по каждому шаблону отвечает «да/нет». «Нет» — дефект,
а не мнение.

**Узнаваемость (главное)**
1. Три страницы одного шаблона выглядят как **один** магазин: шапка, карточка, кнопка, цена, футер — одна вещь.
2. Семь шаблонов рядом выглядят как **одна система** в семи одеждах, а не как семь чужих сайтов.
3. Разницу между шаблонами можно назвать словами: «другая палитра, другой шрифт, другая плотность» — и больше ничем.

**Первый экран**
4. Доминанта одна, её видно сразу; глаз не двоится.
5. Первый товар или первая точка входа в каталог — до сгиба.
6. Заголовок раздела читается как заголовок раздела, а не как жирная строка текста.

**Выкладка**
7. В ряду карточек названия и цены стоят на одной линии.
8. Товар опознаётся по кадру; кадры не спорят друг с другом фоном.
9. Карточка без фотографии выглядит спроектированной, а не сломанной.
10. Цена находится за полсекунды, разряды выровнены.

**Товар**
11. Галерея — галерея: один кадр, миниатюры под ним, тот же кроп.
12. Описание читается: абзацы, строка 60–75 знаков, колонка шире картинки-миниатюры.
13. «В корзину» — единственное главное действие на экране.

**Тон**
14. Ничего не набрано прописными, кроме крошечных моноширинных надглавий.
15. Нет градиентов на контролах, нет второго акцентного цвета, нет цветных декоративных иконок.
16. Низ страницы держит опору: футер тяжелее полотна.

**Мобиль**
17. Ни одной цели, в которую трудно попасть пальцем.
18. Первый экран не пустует и не забит: 12–32 текстовых элемента.
19. Ничего не уезжает вправо.

**Ощущение**
20. Шаблон не читается как «сделано по шаблону»: есть хотя бы один приём, который его характеризует
    (масштаб кадра, ритм полос, работа со словесным знаком) — и этот приём объясняется токеном,
    а не исключением.
