# Лаборатория шаблонов магазина

_Собрано 2026-09-16 11:42 WITA._

Статическая лаборатория: **один прослеживающийся стиль** и **семь шаблонов** на чистых
HTML/CSS/JS, каждый по три страницы (главная, каталог, товар) в двух вьюпортах.
Ничего под `apps/*` не тронуто — перенос на storefront происходит только после того,
как Иван посмотрит.

## Куда смотреть

1. **`gallery/index.html`** — открыть в браузере. Все шаблоны рядом, чек-лист из двадцати
   критериев сбоку, кадр открывает живую страницу.
2. **`design/diagnosis.md`** — почему нынешний результат читается как некачественный:
   двадцать две находки, каждая с числом и кадром живого магазина.
3. **`design/style-spec.md`** — сам язык: шкалы, роли, грамматика компонентов и явный
   список того, чем шаблону отличаться МОЖНО, а чем нельзя.
4. **`design/quality-rules.md`** — тридцать два правила с порогами. Это не манифест,
   а спецификация `check.mjs`.

## Как устроено

```
design/     diagnosis.md · quality-rules.md · style-spec.md · before/ (кадры живого магазина) · mockups/
src/
  tokens/base.css        ЕДИНСТВЕННОЕ место с литеральными значениями
  base/elements.css      сброс, типографические роли, контейнер, сетка, контролы
  blocks/<блок>/         index.mjs (рендер) · style.css · script.js
  templates/<шаблон>.json  композиция + палитра + шрифты + плотность + контент
  lib/                   html.mjs · icons.mjs · media.mjs (генератор SVG)
assets/     base.css · t-<шаблон>.css · lab.js · fonts/ · media/<шаблон>/*.svg
dist/<шаблон>/{index,catalog,product}.html
shots/      42 кадра WebP, каждый ≤ 200 КБ
gallery/    витрина для приёмки
```

Команды (из этого каталога):

```bash
node fonts.mjs      # один раз: скачать восемь кириллических семейств в assets/fonts/
node build.mjs      # JSON шаблонов → dist/*.html + assets/*.css + SVG; идемпотентно
node check.mjs      # машинный гейт: 32 правила; rc≠0 при нарушении
node shots.mjs      # кадры в shots/
node gallery.mjs    # витрина из dist/index.json + shots + §Checklist спеки
```

## Что делает стиль прослеживающимся

Шаблон — это **композиция плюс палитра, пара шрифтов, плотность, число колонок и
соотношение кадра**. Всё остальное общее и защищено проверкой: типографическая шкала
(отношение 1.25, семь ступеней), шкала отступов (кратные 4, десять ступеней), радиусы
(6/8/12/pill), одна рецептура тени, волосяная граница, грамматика компонентов.

`check.mjs` печатает таблицу `QR-TOKEN-COVERAGE` — какие токены переопределяет каждый
шаблон. Если там появится `--text-*`, `--space-*` или `--r-*`, стиль перестал быть общим,
и проверка откажет. Это машинное доказательство, а не обещание.

## Изображения

Все кадры — **сгенерированные SVG**, а не фотографии: судится стиль, и чужая фотография
либо тащит лицензию, либо подменяет предмет спора. Двадцать силуэтов (банка, бутылка, туба,
дой-пак, короб, блистер, прибор, свеча, мыло, стул, лампа, диван, стол, рубашка, платье,
обувь, сумка, книга, гаджет, канистра), семь композиций героя и плитки категорий рисуются
из палитры шаблона детерминированно по имени товара — поэтому сборка идемпотентна.

Шрифты лежат локально (`assets/fonts/`, 46 начертаний, 1,2 МБ): шаблон, открытый без сети,
обязан выглядеть так же, иначе Иван судит системный фолбэк.

**Замер на 2026-09-16:** из двенадцати семейств, которые разрешает профиль витрины
(`apps/storefront/src/lib/theme/fonts.ts`), **кириллицы нет у четырёх** — DM Sans,
Space Grotesk, Fraunces, Sora. Русский магазин, выбравший любое из них, получит системный
фолбэк вместо своего шрифта. В лаборатории используются только восемь оставшихся.

## Чего в лаборатории нет и почему

- **Корзина отдельной страницей, личный кабинет, журнал** — это страницы витрины, а не
  вопрос стиля; журнал уже сделан задачей `b18-blog-full`.
- **Микроразметка и аналитика** — ставятся при переносе на storefront, в статике им
  нечего описывать.
- **Живой поиск с подсказками, мультивалютность** — поведение, а не вид.
- **Тёмная тема** — словарь токенов её допускает (имена ролей витринные), но значения
  для тёмного режима в лаборатории не заданы: Иван судит светлый вид.

## Перенос на storefront

Имена цветовых ролей взяты из витринного словаря один в один
(`specs/design-system/themes/*.theme.json`), поэтому перенос — это подстановка значений
в существующий контракт. Лаборатория добавляет к словарю семь имён, которых витрине
не хватает: `--surface-media` (одна подложка под все товарные кадры), пять `--aspect-*`
и `--media-fit`. `--r-md` равен витринному `--radius`.
