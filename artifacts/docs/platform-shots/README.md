# W7 — «Магазины» admin section screenshots

Captured against the live backend `http://localhost:9025/app` (login `admin@upready.dev` /
`supersecret`) with `shoot.mjs` (Playwright, 1440×900, `chromium-headless-shell` channel — the
only Chromium build cached on this machine). Re-run: `node shoot.mjs` from this directory's
parent (`node artifacts/docs/platform-shots/shoot.mjs` from the repo root). Each run creates and
deletes one throwaway tenant (`w7-shot-<timestamp>`); it does not touch the other tenants shown
in `01-list.png` (`initech`, `globex`, `acme` — seeded by other night workers).

| File | URL | What it proves |
|---|---|---|

| `02-create.png` | `http://localhost:9025/app/tenants` (FocusModal open) | Create form: name, handle with the format hint, first-admin fields (email/password/first/last name). |

| `04-admin-edit.png` | `http://localhost:9025/app/tenants/:id` (Drawer open) | "Сменить email и пароль" drawer for an existing tenant admin, opened from the admins table row action. |

Generated by `shoot.mjs` in this directory (kept re-runnable — see the script's own comments for
