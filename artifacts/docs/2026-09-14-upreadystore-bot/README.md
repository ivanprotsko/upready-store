# Приёмка: бот @upreadystore_bot (ветка `feature/upreadystore_bot`)

Что проверялось: диплинк страницы тарифов `https://t.me/upreadystore_bot?start=plan_<n>` приводит
к ОДНОМУ сообщению с описанием выбранного тарифа и двумя кнопками оплаты, а незаданная платёжная
ссылка не превращается в мёртвую кнопку.

## Чем снято

| Файл | Что в нём |
|---|---|
| `run-live.log` | Живой процесс на БОЕВОМ токене: `getMe` ответил `upreadystore_bot`, дальше длинный опрос Telegram. Здесь же видно, каких платёжных ссылок не хватает |
| `capture.mjs` | Съёмник: поднимает локальный приёмник Bot API, запускает НАСТОЯЩИЙ `apps/bot/src/index.ts` и кормит его апдейтами той формы, какую шлёт Telegram |
| `capture-no-links.{json,md,operator.log}` | Исходящие `sendMessage` в сегодняшнем состоянии: ссылок Tribute ещё нет |
| `capture-with-links.{json,md,operator.log}` | Те же пять сценариев, когда шесть переменных заданы |

Боевой токен участвует только в `run-live.log`; съёмник работает с заглушкой, наружу не отправляет
ничего. Отправка боевым ботом в чужой чат закрыта правилом 17b, поэтому реальные три сообщения в
свой Telegram нажимает Иван — бот для этого оставлен запущенным.

## Результат — пять сценариев, оба состояния конфига

| Пришло | Ссылок нет (сейчас) | Ссылки заданы |
|---|---|---|
| `/start plan_1` | «Новичок», кнопок нет, текст: тариф бесплатный, магазин создаётся в мастере | «Новичок» + две кнопки |
| `/start plan_2` | «Профи», кнопок нет, текст: «Оплату сейчас подключаем» | «Профи» + «Оплатить картой РФ или МИР» и «Оплатить картой Visa/MasterCard» |
| `/start plan_3` | «Мастер», кнопок нет, тот же текст | «Мастер» + те же две кнопки |
| `/start` без payload | Приветствие + выбор из трёх тарифов | То же |
| Нажатие «Профи» в меню | Сообщение тарифа «Профи» | Сообщение «Профи» + две кнопки |

Мёртвых кнопок нет ни в одном снятом ответе: `reply_markup` отсутствует везде, где отсутствует
адрес. Каждая дырка названа в логе оператора именем переменной, которой не хватило —
`payment.link.missing` при старте и `payment.link.missing.onSend` на каждой отправке.

## Что осталось за кадром

Три реальных сообщения в Telegram появятся, когда Иван откроет три ссылки: живой бот запущен и
отвечает. Тексты, которые он там увидит, — дословно те, что лежат в `capture-no-links.md`.
