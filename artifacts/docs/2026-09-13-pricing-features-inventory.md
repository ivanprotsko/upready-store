## 2. Допущения, которых нет в спецификации (решает Иван)

1. **Языки витрины в «Бесплатном» и «Бизнесе» — один.** Спецификация называет «любое количество» только для «Про» и требует одинаковых строк у остальных; старая касса писала «один язык» для младшего плана.
2. **Дизайн в «Про» — редактор дизайна**, как в «Бизнесе»: старший план не может иметь меньше младшего.
3. **Годовая цена «Про» не задана** — на карточке только помесячная. Если считать по той же скидке −35 %, получится 35 092 ₽ в год; на страницу не вынесено.

## 4. Строки для сравнительной таблицы (предложение для t-2026-09-13-03)

Группы и строки, которые есть у всех четырёх платформ и по которым у нас есть честный ответ:

1. **Цена**: помесячно, за год, бесплатный план, пробный период, комиссия с продаж.
2. **Каталог**: лимит товаров, варианты товара, цифровые товары, импорт.
3. **Дизайн**: шаблоны, редактор, свой код, тёмная тема, мобильная витрина.
4. **Продажи**: способы оплаты, доставка, промокоды, брошенные корзины, Telegram Mini App, маркетплейсы.
5. **Владение**: открытый исходный код, экспорт данных целиком, свой домен, API.
6. **Языки и валюты**: число языков, мультивалютность.
7. **Поддержка**: канал, приоритет, персональный менеджер.
8. **ИИ**: чат-правки, генерация изображений, перевод.

Правило заполнения ячеек upready-store: ✅ и 🟡 — «да» (🟡 с пометкой «в ветке»), 🔵 — «в работе / переносится», ❌ и ❔ — «нет» или пусто. Ничего из 🔵 не показывать как готовое.
