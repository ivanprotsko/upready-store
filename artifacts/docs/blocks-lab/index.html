Blocks lab · коридор вариантов

ядро + оси × фильтр валидности. Всё содержимое — из каталога магазина

Что здесь

Каждый блок главной — паттерн (Кристофер Александер, упр. upready-studio «block-generation-engine»): у него есть инвариантное ядро — функция для посетителя, обязательные роли и связи между ними — и ограниченный коридор вариантов по нескольким осям, срезанный фильтром валидности. Тронул ядро — блок сменил имя. Данные — не ось: они приходят из профиля бренда.

Ниже четыре семейства: выкладка товаров, хедер, футер и hero в формате галереи. Для каждого записано ядро, оси с диапазонами, что запрещено, и 2–5 точек коридора, у каждой — что она делает иначе. Копия, цены, названия, категории, условия и юрлицо — настоящие, из профилей. Контраст меряется на каждом варианте: копия никогда не лежит на фотографии, замер поднимается до первого красящего предка.
