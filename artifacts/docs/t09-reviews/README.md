# t09-reviews — приёмка

`acceptance.mjs` — приёмочный прогон по живому стенду (правило 18f): покупатель
оставляет отзыв на витрине, страница товара его **не** показывает, владелец
публикует отзыв в панели, страница показывает его и новую среднюю. Средняя
считается в скрипте из оценок, которые вернул API, и сравнивается с той, что
нарисована на СТРАНИЦЕ, — ошибка округления на любой из сторон валит прогон, а
не прячется за скриншотом.

```
node artifacts/docs/t09-reviews/acceptance.mjs
```

Стенд, на котором это мерялось (переменные окружения скрипта — значения по
умолчанию):

| Что | Адрес |
|---|---|
| бэкенд | `http://localhost:9109`, БД `t09_reviews` (копия `upready_store_cherkashina` через `CREATE DATABASE … TEMPLATE`) |
| витрина | `http://cherkashino.localhost:8043` (`next dev -p 8043`) |
| панель | `http://localhost:5209` (`vite --port 5209`, proxy-режим) |
| владелец | `owner-cherkashino@example.test` / `supersecret1` |
| товар | «Натуральный сорбент от отравлений от температуры», `prod_01M29Q5B9CYCJPW20X8TFMY3QR` |

Скрипт идемпотентен: в начале он удаляет свой же отзыв от прошлого прогона
через `DELETE /tenants/reviews/:id` владельца, иначе «стало на один больше»
перестаёт что-либо значить.
