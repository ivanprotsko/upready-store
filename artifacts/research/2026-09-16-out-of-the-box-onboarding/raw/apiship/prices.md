Тарифы на использование сервиса ApiShip
Во всех вариантах тарифов мы предлагаем полноценный функционал. Ключевое отличие Премиум тарифа - это работа в рамках индивидуального договора, согласование с Заказчиком особых требований к сервису и к договору.
Базовый тариф
0,00 руб.
всегда
+ Работа в рамках стандартной [оферты](https://storage.apiship.ru/docs/offer.pdf)
+ Калькуляция - получение стоимости и сроков доставки *
+ Получение списка пунктов выдачи заказа (ПВЗ)
+ Создание и передача заказа на доставку
+ Получение сопроводительных документов, этикетка
+ Функция вызова курьера
+ Трекинг - получение статусов по заказам
+ Подключение/отключение служб доставки
+ Просмотр созданных заказов
+ Служба технической поддержки (формат 8/5)

5,00 руб. за заказ
минимум 25 000 руб. / месяц (без НДС)**
Включено всё, что входит в Базовый тариф, плюс:
+ Работа в рамках индивидуального договора
+ [Дополнительные опции](https://apiship.ru/prices#options) включены в тариф

* Опция "Калькуляция" - имеет лимит в 10'000 запросов на каждый месяц, плюс за каждый созданный заказ дополнительно начисляется 1'000 калькуляций. Если у вас количество запросов на расчеты имеет массовый характер, либо если вы не используете функционал создания заказов, функция получения расчетов будет ограничена при исчерпании лимита. В данном случае возможно продолжить работу функции в рамках платной опции " [Калькуляция](https://apiship.ru/prices#options) " - 0,01 руб. за запрос (без НДС).
** Тарифы указаны на Сайте без учета применяемого налога на добавленную стоимость (НДС), если прямо не указано иное. Сумма НДС рассчитывается дополнительно, сверх вознаграждения Исполнителя по действующей налоговой ставке.
В соответствии с изменением ст. 164 НК РФ с 01 января 2026 года размер НДС рассчитывается по ставке 22%.
Регистрация в сервисе ApiShip
Для подключения и применения сервисов ApiShip - регистрация Пользователя обязательна. Это бесплатно. По умолчанию вы начинаете работу в рамках действующей оферты, по Базовому тарифу.
Авторизация
Для подключения и использования сервисов Платформы ApiShip - регистрация Пользователя обязательна. При регистрации на Сайте необходимо указывать действующий адрес электронной почты. Подтвердить адрес, перейдя по ссылке в полученном письме. На форме регистрации придумать свой пароль для авторизации.
Оферта
При первичной регистрации на сайте необходимо ознакомится и принять оферту по использованию веб-сервисов ApiShip. Действующая редакция Договора-Оферты, размещена в сети по данной ссылке: [offer.pdf](https://storage.apiship.ru/docs/offer.pdf)
Личный кабинет
В личном кабинете Пользователя отображается:
Данные вашего аккаунта – логин, API Token.
Лицевой счет Пользователя – баланс денежных средств на аккаунте Пользователя, при необходимости использования дополнительных сервисов и опций.
Счетчик калькуляций – доступное количество транзакций по расчетам стоимости тарифов.

Дополнительные опции сервиса ApiShip
Расширенный функционал может быть подключен Пользователем по желанию и при необходимости. Мы решили не делать дополнительных тарифов для опций и рассчитывать стоимость услуг по транзакционной модели - по количеству заказов, участвующих в обработке того или иного сервиса. Подключайте только необходимые опции, в нужном объеме, по нужным службам и направлениям - это более доступно и не затратно.
Опция "Калькуляция"
0,01 руб. (без НДС)
Опция «Калькуляция» является бесплатной, но лимитированной. Ежемесячно на аккаунт Пользователя начисляется 10’000 калькуляций на Счетчик калькуляций. Дополнительно, за каждый созданный заказ начисляется 1’000 калькуляций.
Опция «Калькуляция» работает на аккаунте Пользователя при положительном балансе Счетчика калькуляций. При достижении 0 (нуля) – система будет списывать с Лицевого счета Пользователя сумму за произведенные с этого момента калькуляции, по 1 (одной) копейке за запрос.
Редактор тарифов, создание правил доставки
0,00 руб. (без НДС)
Простой и удобный инструмент для создания правил доставки - управления тарифами, фильтрации и модификации передаваемой информации. Доступен для всех Пользователей в рамках личного кабинета. Бесплатная опция.
