Инструкция по старту работы с сервисами ApiShip
Инструкция по начальной настройке сервиса ApiShip. Описание личного кабинета Пользователя. Подключение служб доставки, тестирование.
[Зарегистрироваться](https://a.apiship.ru/#/signup)
Регистрация
Если у вас уже есть аккаунт в ApiShip - введите логин/пароль для входа в Личный Кабинет (ЛК).
Если забыли пароль - можно воспользоваться функцией восстановления. Потребуется указать e-mail, на который придет сообщение со ссылкой на изменение пароля.
Если вы регистрируетесь впервые - перейдите на соответствующую форму, укажите ваш рабочий e-mail, на него придет подтверждение регистрации. Регистрируясь, вы принимаете публичную оферту.
Регистрация бесплатная! Для тестирования сервисов вы можете создать обычный аккаунт.
[Вход в личный кабинет](https://a.apiship.ru/#/login)
Подключение служб доставки
После регистрации и входа в ЛК вы попадаете на основной Dashbord с общей информацией.
Для начала работы вам необходимо подключить службы доставки, с которыми вы планируете работать.
Перейдите в раздел "Службы доставки", где будут отражены все службы, доступные для подключения. Щелкните на иконку нужной службы, вы попадете на форму "Создания подключения". Данные для подключения у каждой службы отличаются, нужную информацию вы получаете в рамках своего договора со службой доставки.
Тестовый режим устанавливается в настройках, либо, для некоторых служб, используются отдельные ключи доступа.
Чтобы проверить доступные службы доставки, необязательно регистрироваться, можно уточнить на странице по ссылке ниже.
[Все доступные службы доставки](https://apiship.ru/couriers)
Редактор тарифов
При необходимости (не обязательно для интеграции) вы можете настроить правила для отображения расчетов тарифов по подключенным службам доставки.
Данные правила фильтруют передаваемую информацию от служб доставки, модифицируют и корректируют варианты отображения по вашим настройкам.
Перейдите в раздел "Редактор тарифов", нажмите на кнопку "Создать правило". Выберите действие, которое вы хотите чтобы произошло, и условие при котором оно сработает. Сохраните. Порядок применения правил выполняется по очереди, некоторые правила могут влиять друг на друга.
[Видео инструкция и примеры правил](https://docs.apiship.ru/docs/tariff-editor/)
Интеграция
Для работы вам необходимо произвести интеграцию с нашим сервисом по API, либо использовать один из доступных модулей для магазинов.
Для интеграции по API - переходите в [Документацию](https://docs.apiship.ru/docs/api/) . Консультируйтесь с нашей службой поддержки.
Для просмотра доступных модулей, переходите на страницу " [Модули для магазинов](https://apiship.ru/modules) ". Готовые модули могут быть разработаны нами (также отражаются и устанавливаются в нашем ЛК), либо разработаны сторонними разработчиками (в данном случае переходите на сайт разработчика, либо на маркетплейс решений платформы, на которой вы работаете).
Установите модуль и выполните настройки по инструкции.
[Доступные модули для интернет-магазинов](https://apiship.ru/modules)
Раздел "Заказы"
После выполнения интеграции или установки Модуля, вы можете осуществлять работу с сервисами из своей системы. Здесь и далее рассказываем о дополнительных возможностях личного кабинета ApiShip.
В разделе "Заказы" отображаются все созданные вами заказы, созданные при помощи наших сервисов.
Вы можете посмотреть детальную информацию по каждому заказу, а также посмотреть журнал по статусам запросов и ответов по заказу. Уточнить X-Traicing-Id (например, если потребуется для службы поддержки, при возникновении ошибки или вопросов).
[Подробное описание в документации по функции "Журнал запросов"](https://docs.apiship.ru/docs/personal-area/journal/)
Раздел "Калькулятор"
Здесь вы можете рассчитать стоимость по подключенным службам доставки. Не обязателен для интеграции по API или при работе через " [Модули для магазинов](https://apiship.ru/modules) ". Используется справочно или для тестирования.
Перейдите в раздел "Калькулятор", заполните параметры запроса. Заполните расширенные параметры для более точного расчета. В ответ будут отображены расчеты по доступным вам тарифам.
Обратите внимание! Для расчетов стоимости и создания заказов в рамках личного кабинета ApiShip необходимо выполнить создание магазина в разделе "Настройки".
Подробнее о настройках магазина в личном кабинете ApiShip
Функция "Создать заказ"
Вы можете создавать заказы на доставку в рамках личного кабинета ApiShip. Если вы не применяете модули и не интегрированы по API, данная функция позволяет создавать заказы в ручном режиме и по сути является единым личным кабинетом для всех служб.
Кнопка создания заказа есть на основном экране "Dashboard" и в разделе "Заказы".
Нажмите на "+Новый заказ " и перейдите в форму создания заказа. Заполните необходимые параметры, добавьте необходимые товары и места, выберете нужный тип доставки. Нажмите "Рассчитать". Далее, выберете нужный тариф и службу доставки для создания заказа.
Обратите внимание! Для расчетов стоимости и создания заказов в рамках личного кабинета ApiShip необходимо выполнить создание магазина в разделе "Настройки".
