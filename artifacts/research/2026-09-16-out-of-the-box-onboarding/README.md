# Исследование «всё из коробки» — r04-out-of-the-box-onboarding

Составлено 2026-09-16 12:40 WITA. Приказ Ивана 2026-09-16 11:37 WITA: можем ли мы стать посредником, который сам
подключает клиенту Robokassa, ЮKassa, СДЭК, Почту России и Яндекс ID.

**Начинать с `report.md`** — это решение для Ивана. Остальное — его доказательная база.

| Файл | Что это |
|---|---|
| `report.md` | отчёт: ответы на вопросы 1–4 по каждому сервису, три модели передачи доступов, развилки, §Экономия, приложение с 60 цитатами |
| `services.json` + `services.schema.json` | машиночитаемая сводка: программы, шаги с пометкой «кто делает», денежный поток, правила доступа |
| `claims.json` | 60 утверждений, у каждого — дословная цитата, URL и файл сырья |
| `kits/*.md` | пять наборов: пошаговая инструкция клиенту + план видео |
| `offer-clause-draft.md` | **ЧЕРНОВИК** пункта оферты §6А, требует юриста; шесть вопросов юристу в конце |
| `onboarding-tasks.json` | 12 задач в форме tasks.json (ob01…ob12), приоритеты must/should/later |
| `raw/` | сырьё: 62 файла первоисточников, включая оферты PDF-ом; `raw/_izmereniya/` — замер доступности хостов |
| `fetch-log.jsonl` | журнал загрузки: что, когда, каким кодом ответило |

## Проверить всё одной командой

```sh
cd artifacts/research/2026-09-16-out-of-the-box-onboarding
node scripts/verify-claims.mjs && node scripts/validate-services.mjs && \
node scripts/check-report-refs.mjs && node scripts/check-no-secrets.mjs
```

Четыре гейта: цитата найдена в сырье дословно · схема и живость ссылок · ссылки в тексте отчёта ·
отсутствие значений ключей и паролей. Любой красный — это дефект отчёта, а не придирка.

## Чего здесь нет

Решения о модели передачи доступов — это развилка Ивана (раздел 7 отчёта) — и правовых выводов:
всё юридическое помечено «требует юриста». Живые страницы cdek.ru и www.pochta.ru для наших машин
закрыты, поэтому часть ответов честно помечена «не найдено в источниках».
