# Пачка: локали — три рукописные копии каталога, имена доставки по локали сборки, скелетон вместо третьего состояния

Четыре пункта одной области, оставлены приёмками t06 и f06. Источники:
- `logs/accept-t06-locale-currency-2.findings.md`, раздел «Ниты», пункты 1, 2 и 3;
- `logs/accept-f06-shipping-method-names-1.findings.md`, «Мелочи», пункт 2.

## Что замерено

1. **Каталог локалей написан руками в ТРЁХ местах**: `apps/storefront/src/i18n/config.ts`,
   `apps/backend/.../validators.ts`, `apps/tenant-panel/src/lib/locale-catalog.ts` (36 кодов + подписи).
   Общего пакета между apps нет — это признано в теле PR #26. Расхождение теперь возможно молча.
2. **Имя способа доставки по умолчанию берётся из локали СБОРКИ.** Шаг 5 энтрипойнта читает
   `STOREFRONT_DEFAULT_LOCALE` — одну на весь бэкенд, поэтому все тенанты стенда сойдутся на имена ОДНОЙ
   локали независимо от языка магазина. Сегодня все магазины `ru`, и это незаметно.
3. **`routes/settings/locale/locale.tsx`**: `if (isPending) return <SingleColumnPageSkeleton/>` стоит ПЕРЕД
   рендером, поэтому ветка `disabled={!loaded}` почти недостижима — третье состояние по правилу 19h
   реализовано, но на экране его показывает скелетон, а не задизейбленный реальный контрол.
4. **Бездефисный флаг `dry-run`** у бэкфилла локалей — нестандартная форма, нигде не записана.

## Что сделать

1. Один источник каталога локалей. Общий пакет `@upready/*` — правильная форма (видение reuse-library), но если
   он тянет за собой сборочную возню, достаточно **теста-сверки трёх списков**, который краснеет при расхождении.
   Выбери и назови выбор.
2. Имена способов доставки по умолчанию строятся на языке ТЕНАНТА (`default_locale` из `/tenants/locale-settings`,
   задача t06 его уже даёт), а не на `STOREFRONT_DEFAULT_LOCALE`.
3. Скелетон уступает место реальному задизейбленному контролу до ответа сервера (форма 19h как заявлена).
4. Строка про флаг `dry-run` — в README бэкенда или в деплой-инструкцию.

## Критерий готовности

- Тест-сверка: убери одну строку из любого из трёх каталогов — тест красный; верни — зелёный. Покажи оба прогона.
- Два тенанта с разными `default_locale` в ОДНОМ бэкенде: у каждого имена способов доставки по умолчанию на
  своём языке. Замер — `GET /store/shipping-options?cart_id=…` по ключу каждого (как в приёмке f06).
- Экран «Язык и валюта» до ответа сервера: видно реальный контрол в `disabled`, а не скелетон. Скриншот 1280×900
  с искусственно задержанным ответом (лог задержки приложить).
- Строка про `dry-run` в README/инструкции — путь и цитата в отчёте.
