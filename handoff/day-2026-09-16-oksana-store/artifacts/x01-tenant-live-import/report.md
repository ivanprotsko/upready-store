## 5. Находка: контентные страницы читаются витриной по-английски

Данные на месте — мешает **устаревший образ бэкенда на проде**.

Что отвечает витрина сейчас:

| URL | Код | Что видно |
|---|---|---|
| https://cherkashino.shipshift.dev/ru/pages/offer | **404** | «Страница не найдена» |
| https://cherkashino.shipshift.dev/ru/pages/contacts | **404** | «Страница не найдена» |
| https://cherkashino.shipshift.dev/ru/pages/privacy | **404** | «Страница не найдена» |
| https://cherkashino.shipshift.dev/ru/pages/about | 200 | английский текст «Oksana Cherkashina's health store — natural remedies…» |

При этом русские строки **записаны и опубликованы** (`GET /tenants/pages?locale=ru` под владельцем):

```
contacts/ru/pub=true/3417b | about/ru/pub=true/561b | privacy/ru/pub=true/15821b | offer/ru/pub=true/19274b
```

Причина прочитана в коде, а не предположена. Задеплоен sha `bd4ced7` (образы mt-backend/mt-storefront
от 2026-09-14 21:35/21:37 CEST, отчёт d01-deploy-mt). В нём публичный маршрут фильтрует по
жёсткой локали:

```
// bd4ced7:apps/backend/src/api/store/tenant/pages/[key]/route.ts
const [row] = await tenantModuleService.listTenantPages({ tenant_id, key, locale: DEFAULT_PAGE_LOCALE, published: true });
```

Фикс локали посетителя (`requestedPageLocale` + `pickPageForLocale` с фолбэком) уже в `dev`, но
пришёл ПОСЛЕ этого деплоя — коммитом `8b8b482` «feat(cherkashina-migration): … (t02-cherkashina-port) (#21)»
(`git log bd4ced7..origin/dev -- apps/backend/src/api/store/tenant/pages` = ровно один этот коммит).
`?locale=ru` задеплоенный маршрут игнорирует — проверено: `/store/tenant/pages/offer?locale=ru` → `not_found`.

**Вывод: нужна волна деплоя 2 (`dev` ≥ `8b8b482`) — после неё четыре страницы станут русскими без
повторного импорта, данные уже лежат.** Сам не деплоил (правило 21c, и задача это запрещает).

## 7. Что удивило / находки для Ивана

1. **Перемежающийся 502 на `POST /auth/tenant/emailpass`.** Трижды уронил прогон (фазы images,
   pages, замер). Замерил: 30 последовательных запросов с заведомо неверным паролем → **29 × 401 и 1 × 502**
   (~3 %), при этом `/health` 10/10 = 200. То есть маршрут авторизации тенанта иногда отваливается,
   а health этого не показывает. Обошёл ретраями. Предложение задачи: разобраться в логах mt-backend —
   любой скрипт и сама панель владельца будут спотыкаться на этом же.
2. **`GET /store/product-categories` не ограничен тенантом**: отдаёт все 72 категории платформы,
   включая чужие магазины (`forms-barhst`, `spheres-accept-domains-1107`…). Тенант-скоупный
   `/store/tenant/product-categories` отвечает правильно (9). Считал по нему.
3. **Пустая категория «Стимуляторы» стоит в меню витрины** — пункт есть, товаров нет. Пуста в источнике;
   решение (скрыть пустые категории или наполнить) — за Оксаной.
4. **`setsid` на macOS нет** — первый запуск фоновой загрузки молча не стартовал. Формы BSD, не GNU.
