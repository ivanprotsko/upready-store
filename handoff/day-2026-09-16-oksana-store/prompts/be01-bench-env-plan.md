## Что выяснить по первоисточникам (сохранять raw)
1. Как изолировать профиль Claude Code: переменные окружения и пути конфигурации (документация https://code.claude.com/docs/ — страницы settings, environment variables, hooks, memory, `claude -p`, `--output-format stream-json`, `--session-id`/`--resume`), где лежат хуки/правила/память в окружении Ивана (`~/.claude/settings.json`, `~/.claude/CLAUDE.md`, `~/r/`, `~/upready/memory/`, `~/upready/.ai/scripts/`) — как их выключить группами для аблации, не ломая рабочее окружение (отдельный HOME/CONFIG_DIR, а не правки живых файлов).
2. Как считать токены и стоимость: стенограммы `~/.claude/projects/<dir>/<session>.jsonl` — поля usage по `requestId` (ВАЖНО: поле одинаково во всех строках одного requestId — это итог запроса, суммировать по ключам requestId, не по строкам; правило из `~/r/20.md`), прайс моделей — только с официальной страницы цен Anthropic (URL, дата).
3. Как оператор-скрипт отвечает на вопросы агента: детект вопроса в stream-json (`AskUserQuestion`, конец хода с вопросительным текстом), FAQ ответов по ключевым словам, счётчик вопросов, стоп по таймауту.
4. Эталонное приложение: список классов работ из `{{MISSION_DIR}}/tasks.json` (kind/lane/title) — составь задание на 8–12 подзадач, покрывающих классы (backend-модуль + миграция, страница витрины с SEO и локалями, форма панели, интеграция с внешним API по мокам, тесты, деплой-скрипт без живого хоста, документ RU/EN, правка по «жалобе пользователя»), формулировки промптов такие, какие пишет Иван (примеры — INTAKE.md дня), скрытые e2e-тесты (Playwright/node:test) на каждую подзадачу, написанные ДО прогона и не показанные агенту.
5. Дизайн эксперимента: ≥3 прогона на руку, одна модель (sonnet) в обеих руках, порядок рандомизирован, метрики с единицами и грануляцией (18e), таблица «рука × метрика × прогон», аблация по группам, критерий достоверности (разброс между прогонами против разницы рук), стоимость всего эксперимента в токенах/квоте и часах стены, расписание запуска ночью через движок дня (какие задачи заводить, `runner`/`model`, что нельзя запускать параллельно с рабочими задачами).
6. Публикация: структура публичного репозитория (задание, тесты, оператор-скрипт, сырые логи с вычищенными секретами — что именно чистить и чем), лицензия, как студент воспроизводит.
