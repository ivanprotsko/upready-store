Дословно: «модели для сравнения статистики ошибок и модели которые будем использовать для приёмки задач должны получать одинаковые задачи, но я предлагаю поступить следующим образом: 1.1. сначала запускаем выполнять задачу модель gemini 1.2. запускаем сессии приёмки для сравнения 1.3. если находятся ошибки, то запускаем модель аналогичную по уровню той модели gemini 1.4. затем проверяем результат работы этой модели 1.5. если модель допустила такую же ошибку, можно запустить еще один круг приёмки для поиска ошибок».

В плане: (а) каждую новую задачу первой выполняет gemini (через `runner: "agy"`, модель по классу задачи); (б) один результат проверяют несколько приёмщиков ПАРАЛЛЕЛЬНО (машинный этап 0, sonnet, opus — одинаковый промпт, разные модели) — это сравнение приёмщиков; (в) при найденных ошибках та же задача от той же базы уходит модели того же уровня (sonnet) — это парное сравнение исполнителей; (г) результат sonnet проходит ту же приёмку; (д) при той же ошибке — ещё один круг приёмки.
