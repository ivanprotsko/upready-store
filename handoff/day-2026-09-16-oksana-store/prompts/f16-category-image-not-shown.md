# Картинка категории сохраняется, но витрина её нигде не показывает

Найдено живой приёмкой панели (`q02-qa-owner`) на реальном магазине Оксаны.

## Что измерено

1. Панель → Категории → «АСД» → «…» → «Редактировать». В форме есть поле **«Изображение»** с кнопкой
   «Загрузить» и подсказкой: **«Показывается плиткой везде, где витрина выводит эту категорию.
   Очистите адрес, чтобы убрать картинку.»**
2. Загрузил файл — панель приняла его и подставила адрес
   `https://shipshift.dev/static/tenants/ten_01M2GQVGEN1204CN90C510DNRG/1789430173564-q02-test-photo.png`,
   «Сохранить» отработало за 6,1 с, имя категории, изменённое тем же сохранением, на витрине появилось
   через ~11 с — то есть сохранение дошло.
3. Витрина: **картинки нет нигде**. Замер `artifacts/q02-qa-owner/drv/s06f-tile2.mjs`:

| Страница | картинка на странице | ссылок категорий с `<img>` |
|---|---|---|
| `/ru` | 0 | 0 из 12 |
| `/ru/store` | 0 | 0 из 12 |
| `/ru/categories/asd-cherkashino` | 0 | 0 из 12 |

## Что уже известно (не начинайте с нуля)

Приёмка покупателем `q01-qa-customer` разобрала соседний симптом (её список «не заведено», пункт 2):
плитки категорий на главной рисуются только если `metadata.image_url` есть **минимум у трёх категорий**
(`apps/storefront/…/app/[locale]/(main)/page.tsx`, функция `tilesForThisShop`), а запасной список профиля
отфильтровывается по чужим handle. То есть владелица может загрузить одну картинку и не увидеть НИЧЕГО,
никакого объяснения при этом не получив.

## Что сделать

- Картинка одной категории должна быть видна там, где витрина эту категорию выводит: на странице категории
  и в каталоге — без всяких «минимум трёх».
- Для блока плиток на главной: либо снять порог, либо честно написать в подсказке панели, сколько картинок
  нужно, и показать в панели, у скольких категорий они уже есть.
- Проверьте, доходит ли `image_url` из панели в данные витрины (поле категории против `metadata`) —
  возможно, витрина читает не то поле, что пишет панель.

Где искать: `apps/tenant-panel/src/routes/categories/` (запись), витрина — страница категории, каталог
и `tilesForThisShop` на главной.

## Приёмка (замером, на живом магазине)

- Загрузить картинку ОДНОЙ категории в панели и увидеть её: (1) на странице `/ru/categories/<handle>`,
  (2) в каталоге, (3) плиткой на главной — либо, если для главной нужен порог, увидеть в панели прямое
  предупреждение об этом.
- В отчёте: три скриншота витрины и `img src` картинки на каждой странице.
- Уборка: вернуть категории исходное состояние (у «АСД» картинки не было).
