   - `write-transport.ts` — the ONLY file that may send a mutation: `wbWrite(endpointId, { params, body }, ctx)`. Gates, all required, checked in this order before any socket: (a) credential from the SEPARATE tenant-secrets slot `wildberries_write` (add it next to `wildberries`); the read slot is never read here; (b) token inspection: expired or bit 30 set → `WbWriteRefused`; (c) tenant switch `wb_write_enabled = true`; (d) a consent row in `wb_write_consent` (tenant_id, op_class, confirmed_by, confirmed_at, note) for the entry's opClass; (e) process env `WB_WRITE_LIVE=1`. Without (e) the call is a DRY RUN: it validates the body against `bodySchema`, writes `wb_write_audit` (tenant_id, op_class, endpoint_id, method, path, payload, payload_sha256, dry_run=true, actor, created_at) and returns `{ dryRun: true }` — zero network. With all gates: sends, journals response status/body, retries nothing on 4xx.
