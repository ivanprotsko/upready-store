# Отличие изменения от шума

Основание — раздел 3 отчёта `artifacts/research/2026-09-14-market-intelligence/report.md`. Реализуется в ветке `feat/mi-templates` (B3).

## 1. Почему нельзя диффить страницы

Замер 2026-09-14 (`raw/measurements/measure.sh`):

| Страница | HTML | Видимый текст | Доля содержания |
|---|---|---|---|
| `wix.com/plans` | 2 108 049 | 15 654 | 0,74 % |
| `shopify.com/pricing` | 1 103 518 | 17 232 | 1,6 % |
| `tilda.cc/pricing/` | 383 585 | 13 917 | 3,6 % |

Дифф по HTML — это на 96–99 % дифф по шуму. Единица сравнения — **нормализованное значение поля**, а не страница и даже не её текст.

## 2. Четыре класса шума и разное лечение

| Класс | Примеры | Лечение |
|---|---|---|
| Косметический | A/B-тест вёрстки, перестановка блоков, «осталось 3 штуки», таймер акции | сравнение полей, а не страниц |
| Контекстный | цена по стране, валюте, локали, для залогиненного | `request_context` — часть идентичности источника; сравнение только внутри совпадающего контекста |
| Транзиентный | 5xx, частичный рендер, капча, 200 с пустым телом, мобильная вёрстка | проверка правдоподобия + подтверждение вторым замером |
| Настоящий | цена изменилась, план переименован, пункт оферты переписан | это продукт |

## 3. Конвейер

```
СНИМОК        код, тело, время, фактический контекст запроса, стоимость прохода
   |
   v
НАБЛЮДЕНИЕ    (источник, якорь, поле) -> нормализованное значение
   |          нормализация: валюта; разделители разрядов; НДС; единица измерения;
   |          базовая цена ОТДЕЛЬНО от скидочной; период ОТДЕЛЬНО от суммы
   v
ИЗМЕНЕНИЕ     переход A -> B, рождается как suspected
   |          отсев: значение внутри исторического коридора с запасом;
   |                 шаг не больше суточного предела;
   |                 тип и валюта не изменились;
   |                 контекст совпадает; снимок не битый
   v
ФАКТ          подтверждено вторым независимым замером -> confirmed
   |          не подтверждено на следующем проходе -> dismissed (со ссылками на оба снимка)
   v
УВЕДОМЛЕНИЕ   по правилу владельца, с гистерезисом
```

## 4. Подтверждение вторым замером

Обязательно. Одним механизмом закрывает три класса сразу:

- транзиент — второй замер вернёт прежнее значение;
- A/B-тест — второй замер попадёт в другую ветку эксперимента;
- персонализация — второй замер с другого выхода даст другую цену, и **это само по себе факт**: источник помечается «цена персонализирована, наблюдение ненадёжно».

Цена механизма — удвоение проходов только на подозрительных наблюдениях, то есть единицы процентов объёма.

## 5. Проверка правдоподобия

Не «изменение больше X %», а три независимых условия. Нарушение любого делает изменение подозрением, а не фактом:

1. значение внутри исторического коридора `[min, max]`, расширенного на запас;
2. шаг не больше суточного предела для этого типа источника;
3. тип значения и валюта не изменились.

Отдельно: **ноль — это не пусто**. Исчезновение значения там, где оно было, — это `implausible`, а не «цена не указана». Замер, на котором это видно: `insales.ru/page/newplans` отвечает HTTP 200 и содержит ноль ценовых токенов, потому что страница стала архивной заметкой 2023 года, оставшись живой по коду ответа.

## 6. Гистерезис уведомлений

- не уведомлять о возврате значения в прежний коридор;
- не уведомлять повторно о том же значении;
- не уведомлять о колебании внутри порога правила;
- по умолчанию — дайджест; мгновенно — только по явно заданному правилу;
- дедупликация по `(rule_id, anchor_id, value)` в таблице `notification`.

## 7. Правовые документы: другой конвейер

```
снимок -> нормализация текста (шапка, подвал, нумерация, пробелы)
       -> текстовый дифф по абзацам
       -> АГЕНТ: для каждого изменённого абзаца — значимость (major/minor/cosmetic) и чем грозит
       -> карточка: раздел | цитата ДО | цитата ПОСЛЕ | одна фраза «что меняет» | ссылка на снимок
```

Требование к карточке: **цитаты дословные**. Пересказ агента без цитаты в карточку не попадает — иначе через месяц проверить нельзя.

Здесь агент оправдан безоговорочно: документов десятки, значимость — суждение, цена одного прохода на Haiku 4.5 при 6 630 символах текста ≈ 0,3 ₽.
