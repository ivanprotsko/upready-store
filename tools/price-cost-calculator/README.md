# Калькулятор себестоимости и цены дополнительного товара

Задача `t-2026-09-14-02`. Отвечает на один вопрос: **сколько стоит нам и сколько должен стоить
покупателю один товар сверх включённых в тариф** — сейчас, на открытых данных, и потом, когда
появятся замеры по нашим собственным магазинам.

Документ модели с допущениями, источниками, формулой и чувствительностью:
`artifacts/docs/2026-09-14-price-cost-model.md`.

## Файлы

| Файл | Что это |
|---|---|
| `model.js` | Вся арифметика. Ни одного импорта UI, DOM, сети и часов. Это тот модуль, который задача `t-2026-09-14-04` переносит в расширение панели администратора. |
| `model.d.ts` | Типы для потребителей на TypeScript. |
| `defaults.js` | Значения по умолчанию и `SOURCES` — паспорт каждой цифры: замер, публикация с датой, допущение или плановый сценарий. |
| `model.test.js` | Тесты арифметики и переключателей, `node --test`. |
| `index.html`, `app.js`, `tokens.css` | UI. `app.js` только отображает и принимает ввод. `tokens.css` — vendor-копия `geist-kit@b0e687b`. |
| `smoke.html` | Браузерная проверка: меняет поля в живой странице и сверяет, что цена пересчиталась. |
| `MEASURE.md` | Чем и как заменить каждое допущение на замер. |

## Запуск

```bash
cd tools/price-cost-calculator
python3 -m http.server 5399       # модули ES не грузятся по file://, нужен любой статический сервер
open http://127.0.0.1:5399/index.html
```

Проверки:

```bash
node --test                        # 21 тест арифметики и переключателей
# браузерная проверка пересчёта:
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
  --virtual-time-budget=8000 --dump-dom http://127.0.0.1:5399/smoke.html | grep -o 'SMOKE [A-Z]*'
```

Шрифты Geist в инструмент не вшиты: без них токены падают на `system-ui` и системный
моноширинный. Палитра, границы, размеры и `tabular-nums` — из канона.

## Как читать результат

Цена собирается снизу вверх, каждая строка видна отдельно:

```
предельная инфраструктура   прирост стоимости пула от одного товара
+ доля фиксированных платежей
+ нагрузка бесплатных тарифов   (переключатель)
= себестоимость
+ маржа                      % к себестоимости и/или фиксированная сумма
= нужно получить на руки
÷ (1 − комиссия − НДС − УСН) накрутка на удержания
= цена товара                округление вверх
```

Строка фиксированных платежей со значением «нет данных» **не превращается в ноль**: она выпадает из
суммы и печатается в блоке «Чего в модели нет». Правило 20a: подставленное значение хуже
найденного нуля.

## Что переносится в панель управления (t-2026-09-14-04)

`model.js` + `defaults.js` целиком, без единой правки. Панель даёт свою форму и берёт `compute(inp)`;
формат `inp` — единственный контракт. Округление, лестница и чувствительность уже внутри модели,
чтобы панель не считала их заново.
